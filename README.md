# Weather App

A simple weather app built with React. Search for any city to see its current temperature and conditions, with a background that changes when it's warm outside.

## Features

- Search any city by name (press Enter)
- Shows the city, country and today's date
- Displays the current temperature in °C and a weather description
- Background changes to a "warm" theme above 16°C

## Built With

- React
- Vite
- OpenWeather API

## Running Locally

1. Run `npm install`
2. Create a `.env` file containing `VITE_WEATHER_API_KEY=your_openweather_key`
3. Run `npm run dev`
